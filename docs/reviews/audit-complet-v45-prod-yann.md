## Top 5 recommandations concretes

**R1 (HAUTE) — Variabilite inter-generations** : les deux runs (#148 vs #151) produisent un resultat quasi identique. Pour un mode "alternatives", injecter un parametre de variation (disposition miroir, palette accent differente, ou substitution fauteuil/meridienne). Sans cela, generer 2 images = payer 2 fois pour le meme resultat.

**R2 (HAUTE) — Distribution laterale gauche** : sur les 2 generations du salon, le coin gauche (cote radiateur) reste vide. Ajouter dans le builder passe 2 : "If one side of the room is empty, place a secondary piece (floor lamp, side table, low stool) to balance the composition laterally."

**R3 (MOYENNE) — Texture sous-mezzanine** : en passe 1, la sous-face de mezzanine en beton coffre est trop lissee. Renforcer : "Preserve concrete formwork texture on slab undersides — apply paint OVER the texture, not a smooth coat."

**R4 (MOYENNE) — Chirurgie iteration** : l'adjust #153 a deplace l'etagere et supprime le pouf. Renforcer la directive d'inventaire : "List every object position BEFORE editing. After the edit, verify EACH object is still at its original position except the one modified."

**R5 (BASSE) — Accessoire de vie** : toutes les generations sont trop "catalogue". Ajouter un micro-detail de vie dans le furniturePrompt : "one open book face-down on the sofa arm, or a ceramic mug on the side table" — casse l'aspect showroom.
