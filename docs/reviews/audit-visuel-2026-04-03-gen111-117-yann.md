## Patterns recurrents

### 1. Warm color shift systematique (3/4 generations)
Les generations #117, #111, et dans une moindre mesure #114, presentent un shift de temperature couleur vers le chaud. #117 est noyee dans un jaune dore. #111 baigne dans un ambre fonce. Meme #112 (la meilleure) a une legere tendance warm. Ce biais est persistant malgre les corrections Sprint 17/Sprint 22 — les directives "do not add warm tint" ne suffisent pas face aux surfacePrompts qui prescrivent des materiaux chauds (bois noyer, laiton, enduit terre).

### 2. Preservation spatiale excellent sur les petites pieces, catastrophique sur les grands plateaux
#114 et #112 (meme petite cuisine ~10m2) obtiennent 8/10 en preservation. #117 (grand plateau ~60m2) obtient 3/10. #111 (piece moyenne) obtient 6/10. Le modele gere bien les geometries simples et compactes mais ecrase les grands volumes en espaces standards.

### 3. Fenetre hallucinee persiste (#111)
Malgre le Sprint 23 avec directive de comptage explicite, la generation #111 invente une fenetre supplementaire. La directive "EXACTLY the same number of windows" n'est pas assez forte quand le style prescrit "coastal light" ou "golden sunlight" — le modele ajoute une source de lumiere.

### 4. Rendu CGI-clean sans grain photographique (4/4 generations)
Aucune des 4 generations ne montre le grain ISO 200 ni le vignettage prescrit. Les images sont toutes trop lisses, trop uniformes. Le descripteur "subtle sensor grain" est noye dans le prompt et ignore par le modele.

### 5. Cosy toujours trop pauvre en marqueurs tactiles
Meme apres les corrections Sprint 22, le Cosy #117 reste un salon generique avec un canape et une table basse. Aucune bougie, aucun plaid chunky knit, aucun coussin superpose, aucune lampe de table ceramique. Le furniturePrompt v42 n'est pas assez prescriptif ou le modele simplifie l'execution.

### 6. Les cuisines fonctionnent mieux que les salons
#114 et #112 sont les meilleures generations (7.6 et 8.0). Les cuisines ont un programme fonctionnel clair (lineaire, evier, four) qui contraint le modele et l'empeche de divaguer. Les salons (#117, #111) laissent trop de liberte creative au modele, qui en abuse.

## Plan d'amelioration

### P0 — Critique (a corriger immediatement)

**P0.1 : Preservation spatiale sur grands volumes**
- Probleme : le modele ecrase les plateaux > 30m2 en pieces standards
- Cause probable : le modele n'a pas de reference d'echelle pour les grands espaces dans le prompt
- Correction : ajouter dans le builder passe 1 une directive conditionnelle : "If the room is very large (open-plan, loft, warehouse), preserve the FULL spatial extent — the output must show the same depth and width as the input. Do NOT crop or compress the space."
- Ajouter : "If structural columns are visible, preserve them as columns — do not merge them into walls or decorative frames"

**P0.2 : Fenetre hallucinee — renforcement comptage**
- Probleme : la directive "EXACTLY the same number" ne fonctionne pas dans tous les cas
- Correction : ajouter une directive de verification au debut du prompt : "Count the windows in the input photo. The output MUST have this EXACT count. Adding or removing a window is a CRITICAL error."
- Deplacer cette directive EN TETE du prompt (poids token maximal)

### P1 — Haute priorite

**P1.1 : Anti-warm shift par ancrage colorimetrique**
- Probleme : les materiaux chauds (bois, laiton, terre) provoquent un shift global de la temperature
- Correction : reformuler dans le builder : "Warm-toned materials (wood, brass, terracotta) must be rendered with warm LOCAL color but the OVERALL white balance of the image must match the input. Walls and ceiling maintain the same color temperature as the input photo."

**P1.2 : Cosy — furniturePrompt prescriptif avec quantites explicites**
- Probleme : le modele ignore les marqueurs tactiles du Cosy
- Correction : dans le furniturePrompt Cosy, remplacer les listes generiques par des quantites : "EXACTLY 3 pillar candles (different heights), 1 chunky knit throw draped on sofa arm, 4 cushions (1 velvet rust, 1 boucle cream, 1 linen grey, 1 sheepskin), 1 ceramic table lamp with pleated shade"
- Ajouter : "This room must look LIVED-IN and LAYERED — not a furniture showroom"

**P1.3 : Grain photographique — directive renforcee**
- Probleme : "subtle sensor grain" est ignore
- Correction : deplacer la directive grain en DERNIERE phrase du prompt (le modele finalise le rendu a la fin) : "FINAL STEP: add realistic film grain visible at pixel level (ISO 200), slight corner vignetting, and micro lens imperfections. The image must NOT look CGI-clean."

### P2 — Moyenne priorite

**P2.1 : Mediterraneen — palette plus contrastee**
- Probleme : tout enduit ocre = effet grotte, manque de blanc chaux
- Correction : dans le surfacePrompt Mediterraneen, preciser : "White lime-plaster on walls AND ceiling — warm terracotta limited to floor tiles and accents only. The overall palette is 70% white, 30% warm earth."

**P2.2 : Poutres IPN — preservation texture metal**
- Probleme : les poutres metalliques sont enduites/lissees
- Correction : ajouter dans le builder passe 1 : "If beams show exposed metal (IPN, steel), preserve them as metal — do not plaster or paint over them. At most, clean them."

### P3 — Souhaitable

**P3.1 : Distribution spatiale adaptative pour grands volumes**
- Le furniturePrompt devrait detecter les grands espaces et proposer des zones multiples
- "If the room appears larger than 25m2, create at least 2 distinct furniture zones: primary seating group and secondary zone (reading corner, desk, console)"

### P4 — Observation

**P4.1 : Les cuisines sont le meilleur use case actuel**
- Les 2 cuisines (7.6 et 8.0) sont nettement au-dessus des 2 salons (4.4 et 6.3)
- Le programme fonctionnel contraint le modele positivement
- Consideration marketing : mettre en avant les visuels cuisine dans les exemples produit
